# Christian Spiritual Topology

Static publication artifact for the Christian Spiritual Topology reflective assessment.

The assessment runs entirely in the visitor's browser. Assessment responses are stored only in that browser's local storage and are not submitted to this repository or an application server.

The site is delivered through GitHub Pages. GitHub may process ordinary request metadata, including IP addresses, to provide and secure the hosting service.
